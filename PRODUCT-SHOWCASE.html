Enterprise Architecture

Built for Scale, Speed & Total Trust

Every layer of BahiKhata has been designed to meet the rigorous demands of enterprise finance.

Multi-Entity & RBAC Workspaces

Operate multiple companies, regional branches, or distinct entities under one secure profile. Switch contexts instantly with URL-persisted state.

  • Role hierarchy: Owner, Editor, Viewer (strictly read-only)
  • Atomic ownership transfer with typed confirmation
  • Email invitation workflows with role assignments

Atomic Bulk Operations

Execute batch updates across 100 entries at a time with guaranteed database transaction isolation. Never risk partial updates or corrupted rollups.

  • Bulk archive, void, delete, or restore with 1 click
  • 10-second instant undo toast with complete restoration
  • Shift+click range selection and header select-all

Row-Level Security & Compliance

22 database-level RLS policies guarantee data isolation between business tenants. Even if frontend code is bypassed, database access is strictly rejected.

  • Anonymous execution completely revoked on public schema
  • Audit stamping triggers prevent client forgery of author tags
  • 23-section consolidated SQL automated verification

Data Sovereignty & Safe Exports

Export ledger books, customer statements, or full databases whenever required. All exported CSVs are sanitized against spreadsheet formula injection attacks.

  • 4-step verified CSV Importer with delta previews
  • Formula-safe CSV export (`=`, `+`, `-`, `@` escaped)
  • Controlled deletion log purge with 30-day retention floor

Universal DataTable System

Single responsive table architecture with zero horizontal scroll at 1024px+. Intelligently folds secondary columns below tablet widths.

  • Auto-transforms to 44px touch cards on smartphones
  • Fit & fill architecture eliminates wasted whitespace
  • Standardized inline row actions + unified More menus

Universal WCAG AA Accessibility

Every control features accessible names, full keyboard focus rings, screen reader announcements, and 100% WCAG AA contrast conformance in both themes.

  • Accessible hover & focus tooltips via Base UI
  • Disabled buttons explain *why* via tooltip `disabledReason`
  • Full keyboard navigation journeys with zero mouse reliance
